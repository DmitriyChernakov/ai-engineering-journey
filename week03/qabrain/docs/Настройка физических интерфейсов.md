1. Открыть Interfaces → Physical.
2. Включить Edit Mode. 
3. (Опция) Включить/выключить порт тумблером On/Off прямо в строке таблицы.
4. Кликнуть по строке интерфейса (например, gigabitethernet 1/0/2) — откроется карточка.
5. В карточке задать:
    - Enable — административный статус порта;
    - Description — описание (до 255 символов);
    - Mode — Routerport (L3, маршрутизируемый) или Switchport (L2);
    - Firewall — участвует ли порт в(zone-based) файерволе;
    - VRF — в какую VRF поместить интерфейс;
    - IP Unnumbered — использовать адрес другого интерфейса;
    - IP Address Primary — Manual (ввести адрес вида x.x.x.x/nn) или DHCP; при необходимости включить IP Secondary;
    - IPv6 — включить и настроить адрес;
    - MAC — сменить MAC-адрес (опционально);
    - MTU (по умолчанию 1500);
    - Speed — auto или жёсткая скорость;
    - History Statistics + Average Load over the Period, sec.
6. Нажать Save в карточке.
7. Нажать Apply внизу — изменения вступят в силу.
