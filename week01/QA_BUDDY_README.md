# QA Buddy v1

CLI-инструмент для генерации тест-кейсов из описания фичи с помощью локальной LLM.

## Что это

QA Buddy принимает описание функциональности и генерирует структурированные тест-кейсы в формате JSON, включая позитивные, негативные и граничные сценарии.

## Стек

- Python 3.14+
- Ollama (qwen2.5:7b)
- Pydantic (валидация)

## Установка

```bash
# Установить Ollama
curl -fsSL https://ollama.com/install.sh | sh

# Скачать модель
ollama pull qwen2.5:7b

# Установить зависимости
pip install ollama pydantic
```
## Использование

```bash
# Через аргумент командной строки
python qa_buddy.py "Форма логина: поля email и пароль, кнопка 'Войти'"

# Или интерактивно
python qa_buddy.py
> Опиши фичу: [введите описание]
```

## Пример вывода

```json
{
  "test_cases": [
    {
      "id": 1,
      "name": "Успешная регистрация с корректными данными",
      "type": "positive",
      "steps": [
        "Открыть страницу регистрации",
        "Заполнить поле 'Имя' 'John Doe'",
        "Заполнить поле 'Email' 'johndoe@example.com'",
        "Заполнить поле 'Пароль' 'Password123'",
        "Подтвердить пароль 'Password123'",
        "Нажать кнопку 'Зарегистрироваться'"
      ],
      "expected_result": "Появляется сообщение об успешной регистрации и перенаправление на страницу входа",
      "priority": "high"
    }
  ]
}
```

## Ограничения
- Требует ~5 ГБ RAM для модели qwen2.5:7b
- Качество зависит от детальности описания фичи
- Не заменяет ручное тестирование, только ускоряет генерацию идей
